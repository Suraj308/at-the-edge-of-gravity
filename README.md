# Spacetime Habitat

This project aims to provide an understanding of how we are affected as we move closer to massive objects and explores the question of whether it is possible to create a habitable home in such environments.

This project uses simplified, physics-inspired models, and all datasets are synthetically generated to examine qualitative gravitational behavior and habitability constraints in a clear and controlled manner.

This is a conceptual and educational project intended to help understand what it feels like to be near a massive object, rather than to make real-world astrophysical or construction predictions.

## Methodology
A synthetic dataset is generated using a simplified gravity inspired spacetime distrtion proxy
A neural network learns it and its reult are compared against the analytical formulation.
